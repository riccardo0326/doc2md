# Document Quality Rubric

Score every criterion from 0 to 2 for each blind-labelled candidate.

| Criterion | 0 | 1 | 2 |
|---|---|---|---|
| Text fidelity | Unusable or mostly missing | Meaning preserved with notable errors | Text is faithful |
| Special characters | Ligatures, umlauts, or symbols are unusable | Minor character errors | Characters are faithful |
| Table fidelity | Table is missing or unusable | Some cells or structure are wrong | Headers and cells are faithful |
| Figure usefulness | Missing or misleading | Basic subject identified | Useful, accurate description |
| Reading order | Content order is unusable | Local ordering errors | Reading order is correct |
